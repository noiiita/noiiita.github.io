Complete Change Map

  • Color Replace cool-blue accent (#3948d2) with warm red-brown (oklch 52% 0.10 28). Paper-white backgrounds instead of pure white/grey. Perceptually balanced dark mode.
  • Fonts Reduce from 6 font families to 2 (serif display + system sans body). Headings: Iowan Old Style / Charter / Georgia. Body: system sans at weight 400. TikTok Sans stays for hero name only.
  • Spacing Body line-height from 2.4rem to 1.65. Consistent section margins. Generous whitespace between sections — borders replace shadow/blur containers.
  • Images Unify all gallery images to 0–3px border-radius, 1px solid border, no shadow. Remove 5 competing radius values (8/10/12/16/24px). Avatar gets 3px radius.
  • Icons Replace Bootstrap/Font Awesome section icons with typographic marks. Replace inline emoji with mono-wrapped labels. Keep social icons minimal.
  • Containers Replace rounded cards + shadows + blur with flat bordered containers. No backdrop-filter on content sections — let borders define hierarchy.
  • Workflow Remove orange gradient circles, replace with numbered mono indicators. Thin border container instead of shadow card. Emoji arrows → text arrows.
  • Nav Preserve glass-effect on scroll (user-requested). Replace pill-shaped nav links with rectangular bordered links. Monospace uppercase labels.
  • Footer Clean separation with border-top. Mono copyright. No decoration.
  • Links Unify link colors to accent. Remove the 200% size hover effect — use underline and color shift instead.
